# 轨道系统 / Orbital system

## Visual contract

Particles organize into layered elliptical paths around a clear core. Each orbit may represent a product, capability, or system layer while remaining part of one ecology.

## Motion model

Assign an orbit radius, eccentricity, inclination, phase, and velocity to each particle. Rotate in local orbit space, then project with depth. Use sparse guide arcs only when labels or system meaning require them.

## Parameters

`orbitCount`, `radiusRange`, `eccentricity`, `inclination`, `velocityRange`, `coreSize`, `trailAlpha`.

Vary speed by radius and avoid identical concentric rings. Reduced motion keeps the orbital structure and pauses rotation.

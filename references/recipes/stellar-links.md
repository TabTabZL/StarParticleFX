# 星辰连线 / Stellar links

## Visual contract

Stars stay spatially stable while local relationships appear as a restrained luminous network. The result should read as intelligence and connection, not a fully meshed wireframe.

## Motion model

Build neighbor candidates once with a spatial grid or k-d tree. Retain at most two or three short edges per node, then animate edge opacity and draw progress from seeded delays. Let pointer proximity briefly strengthen nearby edges without moving the whole field.

## Parameters

`linkDistance`, `maxLinks`, `revealProgress`, `edgeAlpha`, `nodeAlpha`, `pulseSpeed`, `pointerRadius`.

Do not run an all-pairs distance search every frame. Fade links before nodes on exit. Reduced motion shows a sparse completed graph.

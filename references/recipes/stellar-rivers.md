# 星河分流 / Stellar rivers

## Visual contract

One shared field separates into distinct luminous streams that lead toward chapters, products, or choices. Each river needs a clear destination and color identity.

## Motion model

Assign a stream index and normalized path progress. Evaluate cubic Bezier or spline centerlines, then offset particles across the path normal with bounded turbulence. Transition stream assignment gradually from a common source region.

## Parameters

`streamCount`, `paths`, `flowSpeed`, `streamWidth`, `turbulence`, `separationProgress`, `palette`.

Match path endpoints to the actual layout. Do not let decorative streams imply clickable routes unless they are interactive. Reduced motion shows the separated paths.
